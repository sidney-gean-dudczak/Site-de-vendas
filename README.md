# SNEAKERS STORE

## 1. Sobre o projeto

O **SNEAKERS STORE** é um site desenvolvido com o objetivo de apresentar uma loja virtual de tênis. A plataforma permite que os usuários naveguem por diferentes modelos de produtos e acessem páginas com informações específicas de cada tênis.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript, aplicando conceitos fundamentais de desenvolvimento web e organização de interfaces.

## 2. Conceitos aplicados no design

Durante o desenvolvimento do projeto, foram utilizados os seguintes conceitos:

- **Hierarquia visual:** organização dos elementos da página, utilizando classes e IDs para identificar e estilizar componentes importantes, como nomes dos produtos, preços e botões.
- **Proximidade:** agrupamento de informações relacionadas, facilitando a compreensão e a navegação.
- **Contraste:** utilização de diferentes cores para destacar elementos e melhorar a leitura.
- **Alinhamento:** organização dos componentes para manter uma estrutura visual consistente.
- **Repetição e consistência:** utilização de padrões semelhantes entre as páginas, mantendo a identidade visual da loja.
- **Design responsivo:** adaptação do layout para diferentes tamanhos de tela, como computadores, tablets e celulares.
- **Acessibilidade:** implementação de recursos de ampliação e redução do texto, alteração de contraste e restauração das configurações originais.

## 3. Escolhas de design

### Identidade visual

Foi escolhida uma identidade visual com predominância de tons escuros e detalhes em laranja. Essa combinação busca transmitir uma aparência moderna e destacar os elementos importantes da interface.

### Organização dos produtos

Os tênis são apresentados em cards, contendo imagens, nomes e links para acessar suas respectivas páginas.

A utilização desse formato facilita a visualização dos produtos e aplica os conceitos de proximidade, alinhamento e organização de elementos.

### Páginas de detalhes dos produtos

Cada produto possui uma página própria, com imagens, nome, preço, opções de cores, tamanhos e botão de compra.

Essa organização permite separar as informações de cada produto e facilita a navegação do usuário.

### Responsividade

Foram utilizadas técnicas de CSS e media queries para adaptar a disposição dos elementos conforme a largura da tela.

Esse conceito permite que o site seja utilizado em diferentes dispositivos, proporcionando uma experiência de navegação mais adequada.

### Acessibilidade

Foi desenvolvido um painel com recursos para aumentar e diminuir o tamanho do texto, alterar o contraste e restaurar as configurações originais.

Essas funcionalidades utilizam JavaScript para modificar propriedades e classes dos elementos da página.

### Utilização de inteligência artificial

Durante o desenvolvimento, foi utilizado o auxílio de ferramentas de inteligência artificial para a criação de algumas animações e a realização de ajustes necessários no projeto.
